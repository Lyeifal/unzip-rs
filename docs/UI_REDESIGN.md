# 界面与应用设置

更新日期：2026-10-16。本页描述当前工作区界面；早期重构过程见 [UI 变更记录](../CHANGELOG_UI_REDESIGN.md)。

## 页面与窗口

应用包含“自动解压”“打包压缩”“压缩包管理”三个页面，切换时保留页面状态。标题栏提供应用设置、最小化、最大化/还原和关闭操作；透明标题栏固定在页面顶部。内容区使用可用窗口宽度，页面滚动条轨道透明，滚动时显示滑块，停止后隐藏。

下拉菜单使用统一的 `StyledSelect`，输入框、列表选中项和卡片沿用圆角与主题色。分卷大小使用数字输入约束，不显示原生数字步进箭头。

## 右上角应用设置

“界面外观 → 显示标题栏底色”可为软件名称、设置及窗口按钮所在栏添加主题底色，默认关闭以保留透明样式。开关立即生效并保存，重启后恢复；切换浅色或深色主题时底色随主题变化。应用名称统一为 `unzip-rs`，应用图标采用透明底黑色圆角压缩包轮廓，界面内图标使用主题文字颜色以保持可见。

“应用更新”显示当前版本、可用新版本和下载进度。发布版启动时自动检查 GitHub 稳定版；下载与安装需要用户点击，任务运行时禁止安装。更新签名和发布步骤见 [UPDATES.md](./UPDATES.md)。

| 区域 | 可设置内容 | 生效方式 |
|---|---|---|
| 压缩与解压工具 | 7-Zip、UnRAR、可选 lz4.exe 路径 | 点击“保存工具路径”；下次压缩/解压使用新值，无需重启 |
| 压缩包管理 | 密码显示开关；文本、下拉、勾选字段及选项 | 修改后保存本机偏好，管理卡片同步变化 |
| 资源管理器右键菜单 | 启用或关闭添加到压缩/解压列表的入口 | 按当前用户注册，Windows 11 通常在“显示更多选项”内 |
| 主题预设 | 跟随系统、黑白与莫兰迪配色 | 选择后应用，可与壁纸、透明度一起使用 |
| 壁纸与配色 | 上传、移除、自动/手动取色、模糊、暗度和卡片透明度 | 调整后应用并保存本机偏好 |

工具路径留空时使用内置组件或内置解码器。正在运行的任务继续使用启动时的工具；开始新任务会等待正在进行的路径保存，保存失败时提示错误。

## 主题与壁纸

内置主题：

- 跟随系统：随 Windows 当前浅色/深色模式切换。
- 墨黑、暖白。
- 灰鼠尾草、薄雾蓝、燕麦沙、灰玫瑰、暗薰衣草。

上传支持 JPEG、PNG、WebP、AVIF 等图片，单张不超过 5 MiB；具体格式还依赖 WebView2 的解码能力。设置壁纸与取色分开处理，取色失败时保留已应用的壁纸并显示错误。

配色有三种模式：预设、壁纸自动取色和手动颜色。壁纸模式下可以重新提取，手动模式可调整主色、辅助色、强调色及背景色。文字和控件颜色根据背景亮度与对比度自动选择深色或浅色，目标是保持可辨识度，并非简单逐通道反色。

卡片透明度可与壁纸搭配。若背景细节仍影响阅读，可提高卡片不透明度、增加遮罩暗度或模糊程度。主题及壁纸保存在本机 WebView localStorage，不包含在压缩记录 JSON 导出中。

## 通用压缩包管理

管理页直接读取 AppData 集中记录，显示源名称、压缩文件名、输出目录、大小、压缩率、日期和分卷数。带哈希的记录可展开查看各产物 SHA-256。

- 备注支持多行文本，输入变更提交时保存。
- 自定义字段可添加、重命名、排序和移除；下拉选项每行一个。
- 默认提供分类下拉和“已整理”勾选项。
- 旧版本号并入备注，旧引擎和 APK 标记迁为自定义字段；原属性保留。
- 删除字段定义不删除记录值；旧选项仍可显示与筛选。
- 支持按名称、压缩包名、备注或字段值搜索，以及下拉字段筛选和名称/大小/压缩率/日期排序；记录由 SQLite 分页返回，每页 24 条，全库统计与匹配总数单独显示。
- 打包页支持前缀与后缀的选择、启停和新增；数字起点与步长独立填写，自动续号从压缩包管理的同系列记录中计算。前后缀列表保存在本机 WebView localStorage。

“显示压缩包密码”默认关闭，只影响管理卡片；打包结果和记录文件仍可能含明文密码。

### 旧记录和备份

首次打开管理页会尝试导入上次使用的管理目录和打包输出目录中的旧 JSON，也可点击“导入旧 JSON”选择其他记录。已有同路径记录优先保留，不覆盖新备注。“导出备份”保存完整记录，原压缩文件不受影响。

完整字段与恢复方式见 [压缩记录格式](./PACK_MAPPING.md)，备份范围见 [数据存储说明](./STORAGE.md)。

## 解压与打包

解压页提供选中项、源目录和两者合并三种来源方式；仅选中项时无需填写源目录。解压输出目录用于保存解压后的内容，缺少时点击开始会提示并直接弹出目录选择框；打包输出目录也采用相同行为，选择后继续任务，取消则不启动。密码库、密码策略规则、解压选项分别通过按钮打开弹窗。密码排序在密码库中，规则可排序并启停，SHA-256 匹配在策略规则中。失败目录旁的开关可随时停用该目录，保留已选路径，失败源文件和分卷留在原位置。只有核心确认密码不匹配的失败项显示“添加新密码并重试”，仅对该任务尝试新密码；成功后新密码加入密码库。共用工具路径位于应用设置，设置弹窗左侧导航可直接跳到对应区域；解压页设置在开始任务前保存。

打包页统一使用可独立启停的前缀、数字起点、步长和后缀命名，不再显示旧起始包名与命名方式开关。旧本地配置在加载时转换为这组字段。页面还可设置格式、级别、密码模式、分卷阈值、分卷大小和说明文本；每成功打包一个条目即保存密码、产物哈希和统计记录。首次安装时设置页默认显示内置 7-Zip 和 UnRAR 路径，lz4 优先使用内置 Rust 解码器。

资源管理器右键入口将选中项加入相应列表，用户再确认参数并开始任务。解压来源由页内三种模式决定；选择“两者一起”时合并选中项与源目录，重复路径只处理一次。

## 开发入口

| 文件 | 用途 |
|---|---|
| `app/src/App.vue` | 页面、透明标题栏、窗口控制与页面滚动条显示时机 |
| `app/src/styles/themes.css` | 默认主题变量 |
| `app/src/styles/glassmorphism.css` | 公共控件、卡片、列表和滚动条样式 |
| `app/src/styles/animations.css` | 公共动画 |
| `app/src/components/StyledSelect.vue` | 统一下拉框 |
| `app/src/components/ThemeSettings.vue` | 应用设置容器 |
| `app/src/composables/useTheme.ts` | 主题状态、壁纸与持久化 |
| `app/src/utils/colorExtractor.ts` | 取色与对比度配色 |
| `app/src/utils/themePresets.ts` | 系统模式和预设配色 |

此说明不承诺所有透明度与壁纸组合都有相同阅读效果；当前阶段的检查范围见 [实现摘要](./IMPLEMENTATION_SUMMARY.md#检查记录与限制)。
